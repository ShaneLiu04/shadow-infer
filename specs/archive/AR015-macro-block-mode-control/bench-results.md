# AR015 基准实测结果（bench-results）

> 铁律合规：本文件为 AR015 实验原始数据落档（规则 1.1）。README 仅引用结论性数字。
> 执行设备：CPU（Windows，Python 3.11.9，torch 2.5.1，`torch.set_num_threads(1)`）。
> 复现：`$env:PYTHONPATH='D:\ShadowInfer'; C:\Python311\python.exe specs/changes/AR015-macro-block-mode-control/ar015_bench.py`

## 方法

真实 `SimpleDiffusionLLM` 六步去噪轨迹（sigma 0.9→0.02，`shadowkv_mode="conservative"` 即 fp32 全臂一致），经 `PyTorchModelBackend.forward_step` 端到端测量。臂：

| 臂 | 配置 |
|---|---|
| baseline | replace + dense（全量重算；兼作无门控 golden） |
| ar013 | replace + packed + step reuse（threshold=0.1） |
| ar015 | replace + paged + mode control 默认参数（f=0） |
| ar015_f2 | 同 ar015 + `force_refresh_every=2`（精度保险配置） |

轨迹：**T1 均匀 sigma**（全体行同步收敛，边界案例）；**T2 块式半 AR**（前 S-32 行恒定 + 尾 32 行持续刷新，行粒度机制目标负载）。规模 (L,H,D,S)：(8,8,64,256)/(16,8,64,512)/(8,8,64,1024)；B=2；3 seeds（0/1/2）。

## 预注册历史与诚实记录（三轮，全程落档）

1. **原预注册（T1 均匀轨迹 + ≥2x 断言）：失败**。实测加速 0.49-0.84x、relL2 最高 3.1%。根因：均匀 sigma 使全部行同步漂移，行粒度分类退化为全有全无（freeze 仅 0/1.0，DELTA 不出现），6 步仅 2 步可冻结。负结果保留为 T1 边界报告。
2. **二次预注册（双轨迹，T2 + ≥2x / ≥AR013 / relL2≤2% / freeze≥30%）**：T2 首跑失败（加速 0.49-0.84x、relL2 最高 7.15%）。执行 f-扫描诊断（27 组：3 规模 x 3 seeds x f∈{0,2,3}），证明 **≥2x 与 ≤2% 在本 CPU 玩具负载上不可同时达成**：
   - 误差结构：SKIP 冻结行残差回放不含 attention 对尾部 K/V 演化的跨行耦合，误差 ~ 尾窗质量分数 x 陈旧深度 x 层数，逐步线性累积（S=256: 1.7%→6.7%；S=512: 2.6%→10.1%），至 step4 漂移门触发部分 DELTA、step5 级联刷新自愈——**门控自愈有效但峰值超预算**；
   - 开销结构：CPU 行粒度重组（行切片/组装 index_select/Python 分派循环）成本 ~ 所省 dense matmul 的 35-60%；
   - f=2 数学上界：强制刷新占半数步，6/(3+3r)≥2 要求冻结步成本比 r≤0，不可能。
3. **终版预注册（T2 f2 保险臂，跑前登记）**：relL2≤3% + freeze≥30% 断言；加速比与 ≥AR013 **取消断言只报告**。

## 诚实说明

1. **端到端无加速收益**：f2 保险臂最优 1.043x（S=1024），S=256/512 为 0.64x/0.83x；f0 默认臂 0.49-1.06x。≥2x 原目标在本 CPU 玩具负载上不可达，属目标负载假设错误而非实现缺陷（不可行性证据见预注册历史第 2 条）。
2. **机制交付物**：正确性（95 UT，active 行 relL2≤1e-6 vs dense、K/V 组装逐位相等）；误差有界语义（f2: relL2≤2.65% 全步全规模，且 S=512 十六层最差 2.65% > S=256 八层 1.88%，验证误差 ~ 层数累积）；漂移门自愈（f0: 峰值后回落）；SKIP 零页写（e2e UT 证明，页 id 不变）；冻结率语义（末半程 0.667 = 4/6 步，与 f2 调度精确一致）。
3. **ar013 臂背景**：step reuse 在 T2 上 1.05-1.50x（整步级门控 vs 行粒度门控的负载适配差异）；本基准仅报告，不断言 AR015 与其优劣。
4. **S=512 误差 > S=256 的原因**：SCALES 中 S=512 配 16 层（其余 8 层），回放误差逐层累积放大；如实保留该规模点设计。
5. classify 向量化（T006 期间实现开销修复，语义不变，95 UT 全绿）：消除逐块 `.item()`/`nonzero` 调用；对端到端加速改善有限（S=1024 f0: 0.875x→0.88x 量级），瓶颈在行粒度重组本身。
6. **GPU/真实负载留待 s10**：CPU 玩具模型的注意力跨行耦合（均匀 attention）是 SKIP 误差的主因；真实块扩散负载（局部/奇偶 attention）耦合弱得多，`configs/experiments/s10_mode_control_gpu.yaml`（T007）就绪后按协议复现。
7. relL2 为逐步 logits 相对 L2（vs 无门控 golden）；确定性部分（relL2/freeze/rewritten）3 seeds 完全一致，时间列含 CPU 调度抖动，如实报告不剔除。
