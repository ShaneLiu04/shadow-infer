## 1. 校准探针（跑前，单 seed，未注册）

### 1.1 预注册修订：threshold 0.9 → 0.005

设计 §6.5 原定 threshold=0.9。探针实测玩具模型逐轮 softmax-max 置信度分布为
0.004-0.010（vocab=1000 随机初始化输出投影，近均匀分布），0.9 阈值下**所有轮次
top-1 兜底、并行解掩路径零触发、每块打满 max_rounds=8 强制收尾**——机制退化，
基准无法验证「置信度感知」主张。按 AR015 校准纪律做预注册修订：主网格
threshold=0.005（置信分布中位附近，并行解掩触发 ~10-15% 轮次），另设仅报告的
阈值敏感性扫描（0.9 / 0.005 / 0.003，G=192 seed 0）覆盖三个机制态。

### 1.3 探针期机理发现

1. **加速比由行裁剪驱动且阈值鲁棒**：两臂共享调度决策，speedup ≈ 每轮行比
   （baseline 重算 L+W 行 vs 臂活跃前向 W 行）× 轮数比的复合；兜底轮越多，
   行裁剪收益越大；全并行态（0.003）两臂同塌缩，比率收敛向 1.29x。
2. **int8 relL2 双态**：决策对齐点（tokens 逐位一致）relL2 ~3.6e-04，即 int8 KV
   页量化的真实 logits 误差量级；决策分叉点 relL2 ~0.18 为逐轮 logits 错位比较
   的伪影（argmax/阈值边缘翻转级联；count 级决策一致不保证位置级一致，实测
   G=192 seed1 int8 count 一致仍分叉）。fp16（relL2 恒 1.24e-05）12/12 探针点
   零分叉。
3. **kv_writes 恒等于 P+G**（256/512/1024）：每 KV 行写一次、零重写、零逐出；
   baseline 无页写但逐轮全量重算丢弃全部 KV。
4. 小规模诚实结论：G=192（S=256）fp32 speedup 2.26-2.60x，低于 3x——gather 重建
   与 sealing 前向等固定开销在短上下文占比高。

### 2.1 判据修订记录（A6：v1 → v2 → v3）

**v1（首次全量跑）**：以「tokens 逐位一致」为对齐代理。FAIL 2 点（G=448/960
seed=0：bitwise=True 但 relL2=1.727e-01）。诊断（ar016_diag*.py，临时脚本）定位
机制：int8 KV 噪声使 block 13 round 3 两臂在 batch1 上发生**解掩调度置换**——
baseline 解掩 {p5}，臂解掩 {p31}，round 4 互补解掩；两位置最终 token 相同
（505/533，逐位一致成立），但 round 4 上下文错位：互换行自身 embedding 不匹配
（一臂已填真 token、另一臂仍为 mask token，行 relL2≈0.98），其余行因 512 键中
2 个置换仅 ~0.1-0.2%，整轮 relL2=0.173。**终态一致不蕴含逐轮轨迹一致**，v1
代理证伪。

**v2（第二次全量跑）**：改为位置级对齐（逐轮解掩位置张量相等）。实现缺陷：
baseline 侧 `unmask_positions_per_round` 漏写列表级 append，恒为空表 → 空 zip
使 aligned 恒为 True（空洞真），run 2 的 8 个 A6 FAIL 判定**无效**（其数据其余
部分仍有效：A1-A5、A7-A9 全 PASS，数值见 §2.1 末尾交叉核对）。已修复 append。
另经诊断证实 v2 判据在逻辑上也不完备：位置相同 + 中途 token 翻转（近并列
argmax）同样破坏逐轮上下文，位置级单独不充分。

**v3（第三次全量跑，最终判据）**：**轨迹对齐 = 逐轮解掩位置相等 ∧ 终态 tokens
逐位一致**。数学上：位置集合逐轮相同 + 终态相同 ⟹ 每轮填入 token 相同（位置
一旦解掩不再改写，中途 token 不同必然留下终态差异）⟹ 逐轮上下文相同 ⟹ relL2
有意义。对齐点断言 relL2 ≤ 1e-3；非对齐点跳过断言、带标记原值报告。

**int8 误差量级的诊断证据**（临时诊断脚本，非注册资产）：

1. int8 per-channel（head_dim 维）对称量化 K/V 直接往返 relL2 ≈ 5.9e-3（合法
   per-channel 量化的正常量级，utils/quantization.py 实现无缺陷）；
2. (G=448, seed=0) 逐块 relL2 剖面：blocks 0-12 全部干净（3.6e-4 单调衰减至
   2.0e-4），仅 block 13 跳至 0.173（该块发生调度置换，见上）；(G=192, seed=0)
   全程无置换 → 全程 3.6e-4。即**轨迹对齐时 int8 的真实 logits relL2 为
   2.0-3.6e-4**，0.17-0.21 为置换/翻转轮的错位伪影；
3. fp16 12/12 探针点 + 9/9 注册点零分叉，relL2 恒 1.24-1.26e-5（无尺度依赖）。

run 2 交叉核对数据（A1-A5/A7-A9 与 run 1 一致）：fp32/fp16 九点全逐位
（fp32 relL2 max 3.25e-7；fp16 恒 ~1.25e-5）；fp32 speedup 中位
2.231x / 3.681x / 7.176x；int8 token 一致率区间 [0.9961, 1.0000]；kv_writes
逐点 == P+G；敏感性扫描 0.9/0.005/0.003 态 rounds 48/48/6、speedup
2.301x/2.088x/1.202x。

### 3.5 README 引用口径（结论性数字）

- fp32 页精度：相对全量重算参考环路 **2.29x / 3.68x / 7.08x**（S=256/512/1024
  中位，B=2，单线程 CPU 玩具负载），tokens 与逐轮 logits 全逐位一致
  （relL2 ≤ 3.3e-7）；KV 行写一次零重写（P+G 恰好）
- fp16 页精度：relL2 ≤ 1.3e-5，tokens 全逐位（近无损）
- int8 页精度：轨迹对齐点 relL2 3.6e-4；token 一致率 ≥ 0.996（9 点）；
  阈值边缘调度置换/近并列 argmax 翻转可致中途轨迹分叉（伪影 relL2 ~0.17-0.21，
  终态多数仍逐位或 ≥99.6% 一致）
- 小规模（S=256）加速 2.29x 低于 3x：固定开销占比高，如实标注
